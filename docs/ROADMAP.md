## Этап 1 — до публичного запуска (сайт уже работает локально)

- [ ] **Ключ Claude API** в `.env.local` → прогнать 3–5 реальных сайтов, откалибровать
      тексты находок (формулировки, точность штрафов, тон). Это блокер: промпты писались
      «вслепую», без живых ответов.
- [ ] **Домен**: купить sait-checkup.ru (основной, вся техника на нём) + saitcheckup.ru
      и сайт-чекап.рф (редиректы) + dok-checkup.ru (резерв под ДокЧекап). Все свободны
      по DNS на 12.08.2026 — подтвердить у регистратора. Почему .рф не основной — см. SPEC.
      Регистратор любой (Reg.ru подойдёт), он не обязан совпадать с хостингом.
- [ ] **Почта** hello@sait-checkup.ru — Яндекс 360 для бизнеса, бесплатный тариф.
- [ ] **Хостинг**: Timeweb App Platform, деплой из GitHub. Только РФ — локализация ПД
      (ч. 5 ст. 18 152-ФЗ), Vercel исключён. Секреты (`ANTHROPIC_API_KEY`,
      `CHECKUP_SECRET`) — в переменных окружения панели, не в репозитории.
      Настройки, проверено 12.08.2026: тип Frontend → Next.js (в Backend его нет),
      регион **Москва** (SSR доступен только в Москве и Амстердаме, а нам нужна РФ),
      **тумблер «Поддержка SSR» обязателен** — без него собирается статика и все
      `/api/` перестают существовать. Команда запуска `npm start`, директория `.next`
      (по умолчанию подставляется `/out` — это для статики, менять вручную).
      Цена: **510 ₽/мес за 1 ГБ, 810 ₽ за 2 ГБ** — прежняя оценка «300–400 ₽» неверна,
      SSR требует постоянно работающего процесса. Начали с 2 ГБ: сборка Next.js
      прожорливее самого сайта и на 1 ГБ может упасть по памяти.
      `NEXT_PUBLIC_DEV_UNLOCK` на проде НЕ задавать — иначе ссылка «показать полный
      отчёт» раздаёт платный отчёт даром.
- [x] Заменить `alert()` на нормальные состояния. «Войти» в шапке — подсказка под кнопкой
      (закрывается по Esc и клику мимо), в мобильном меню — строка внутри меню.
      Кнопка оплаты — сообщение под кнопкой. Системных окон браузера в коде не осталось.
- [ ] Финальный прогон по чек-листу качества (скилл `10k-website-checklist`) перед анонсом.
      Прогон 13.08.2026 сделан, «невидимое дорогое» починено: контраст вторичного текста
      доведён до WCAG AA (`--c-faint` затемнён, мелкий шрифт в подвале увеличен),
      добавлен видимый фокус с клавиатуры (`:focus-visible`), добавлены og/twitter-метатеги.
      Осталось до анонса:
      - [x] **og-картинка** — генерируется кодом при сборке (`app/opengraph-image.js`),
            1200×630, отдельного макета держать не нужно. Шрифты для неё лежат
            в `assets/fonts/`. Адрес картинки строится от `metadataBase`: пока сайт

            иначе в теге будет `sait-checkup.ru`, которого ещё нет.
      - [x] **Визуальные якоря** — решено 14.08.2026: фотографий и иллюстраций не добавляем,

            превью настоящего отчёта на главной, маскот на странице 404 и типографический

- [x] Результат бесплатной проверки переживает перезагрузку страницы: localStorage, час, потом
      сам стирается. На сервер ничего не пишется, дневной лимит не обходится.
- [x] Мобильное меню — бургер с оверлеем в `components/Header.js`.

## Этап 2 — «Деньги»

- [x] **Публичная оферта** (страница /offer) — обязательна для модерации Продамуса. Написана
      12.08.2026, ссылки в футере и у кнопки оплаты стоят. Решение Юлии от 14.08.2026 —
      идём с этой редакцией, без предварительной вычитки юристом.
      ⚠️ **Оферта описывает состояние после этапа 2, а не сегодняшнее.** В ней обещаны
      личный кабинет, выгрузка PDF и бесплатная перепроверка в течение месяца — ничего
      из этого пока не построено. Включать приём оплаты можно только вместе с ними,
      иначе сервис, который ловит чужие сайты на невыполнимых обещаниях, сам даёт такое же.
- [ ] **База данных**: managed PostgreSQL у Timeweb (НЕ Supabase — локализация ПД).
      Таблицы: проверки, заказы, пользователи, согласия (email + marketing yes/no —
      перенести из временного data/emails.txt).
- [ ] **Продамус**: платёжная ссылка с order_id → вебхук с проверкой подписи →
      разблокировка отчёта. Цена 990 ₽.
- [ ] **Аккаунты без паролей** (magic link): при оплате аккаунт создаётся автоматически
      по email из Продамуса; PDF и история — только после входа.
- [ ] **Ссылки на отчёты** (токен в URL) — «можно отправить подрядчику». Живут месяц, как и сам
      отчёт; после истечения отдавать понятную страницу «срок доступа истёк», а не 404.
- [ ] **PDF-версия отчёта** в кабинете.
- [ ] **Telegram-уведомления владельцу**: новая проверка (URL, оценка) и оплата
      (сумма, сайт, email покупателя).
- [ ] **Лимиты — довести до продакшена**: счётчик пока в памяти процесса, то есть
      обнуляется при перезапуске и не общий между инстансами → перенести в БД.
      Плюс подтверждение почты кодом (сейчас достаточно её оставить),
      платные проверки вне лимитов, Cloudflare Turnstile против ботов.
- [ ] **Перепроверка после правок** — бесплатная в течение месяца после оплаты (обещана на лендинге).
      Срок совпадает со сроком хранения отчёта, см. SPEC.

## Технические заметки

- `npm run build` НЕ запускать при работающем dev-сервере — делят `.next`, dev ломается
  (лечится: остановить dev, удалить `.next`, запустить заново).
- `data/emails.txt` — временное хранилище согласий, в .gitignore; заменить на БД в этапе 2.
- `CHECKUP_SECRET` обязателен в проде: без него роуты падают. В разработке
  подставляется отладочный ключ, поэтому лимиты работают и без `.env.local`.
- Счётчик лимитов лежит в `globalThis`, а не в модульной переменной: Next пересобирает
  модуль между запросами в dev и даёт каждому роуту свой экземпляр в проде.
- Демо-режим (без ANTHROPIC_API_KEY) отдаёт заглушки из app/api/check/route.js — удобно
  для вёрстки, но помнить, что тексты там не настоящие.
