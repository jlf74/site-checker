# СайтЧекап — продуктовые решения

> Зафиксировано в обсуждении с Юлией, июль 2026. Менять — только осознанно.

## Позиционирование
- Самостоятельный продуктовый бренд, НЕ привязан к личному бренду Юлии
  (цель — пассивный доход и линейка «хелперов»; автор упоминается на странице «О сервисе»).
- Ниша широкая («проверка сайта»), акцентная ниша (эксперты/онлайн-школы) — в составе проверок.
- Оффер с юридическим акцентом: защита от штрафов и проверок.
- Отличие от конкурента fzscan.ru: не только юридика (тексты + конверсия),
  человеческий язык отчёта, готовые исправления вместо констатаций.

## Утверждённые тексты
- H1: «Проверьте свой сайт раньше, чем получите штраф»
- Подзаголовок: «Проверка сайта на соответствие 152-ФЗ, законам о рекламе и об образовании. Бесплатно, за 3 минуты.»
- Под кнопкой оплаты: «Подробный отчёт в PDF-формате сразу после оплаты»
- В шапке цену не пишем — пункт меню «Стоимость» + «Войти» + «Проверить бесплатно».

## Дизайн (концепт утверждён)
- Белый фон, синий акцент #2563EB, шрифты Manrope (заголовки) + Inter (текст).
- Зелёный (#1D9E75) — ТОЛЬКО на шкале здоровья сайта.

## Монетизация
- Главный товар — юридическая проверка (152-ФЗ, реклама, образование); текстовые проверки — бонус
  («никто не платит 990 за орфографию»). Чипы на главной сгруппированы: «Юридическая проверка» + «Бонусом: тексты».
- У каждой юридической находки — вилка штрафа (поле fine/fineMax из модели, по КоАП, первичное нарушение).
  На вердикте — «Суммарный риск штрафов: до N ₽» (сумма fineMax). На фоне риска 990 ₽ выглядит дёшево.
- Бесплатно (1/день, без регистрации): оценка + риск ₽ + ВСЕ заголовки находок со штрафами и статьями
  (польза: видно всё, что не так) + первая находка целиком (образец качества) + пункты «в порядке».
  Закрыто: «как исправить» и цитаты остальных находок, PDF, перепроверка.
- Кнопка «+2 бесплатные проверки в день» → регистрация по email (MVP: /api/subscribe пишет в data/emails.txt,
  этап 2 — Supabase + подтверждение кодом + реальные лимиты).
- Полный отчёт — 990 ₽ (Продамус): все исправления, ссылка на отчёт, перепроверка после правок, PDF.
  Слово «постоянная» про ссылку больше не употребляем: отчёт живёт месяц, обещать вечность — врать.
  Вечным остаётся только скачанный PDF.
- **Сроки хранения (решено 12.08.2026):** купленный отчёт лежит в кабинете **месяц**, бесплатная
  перепроверка — тоже **месяц**. Сроки совпадают намеренно: одна понятная формулировка вместо двух.
  PDF скачивается и остаётся у клиента навсегда — это ответ на «заплатил и потерял».
  Дата окончания показывается в кабинете явно, а не считается пользователем.
- **Бесплатные проверки не хранятся вообще.** Результат живёт в localStorage браузера час, чтобы
  пережить перезагрузку страницы, и сам стирается. На сервер не попадает: нечего удалять, нечего
  описывать в политике, не нужна БД. Дневной лимит при этом остаётся серверным — посмотреть старый
  результат можно, запустить новую проверку нельзя. Cookie для этого не годится: лимит 4 КБ,
  отчёт весит 15–30 КБ.
  Цена на фоне конкурентов нормальная: help152.ru — 1490/2990/4900 ₽.
- PDF — только после входа. При оплате аккаунт создаётся автоматически по email из Продамуса (magic link, без паролей).
- Лимиты: IP + cookie; почта подтверждается кодом; Cloudflare Turnstile.

## Многостраничные сайты (экономика токенов)
- Одна проверка одной страницы (до 12к знаков) на Sonnet ≈ 3-4 ₽; все проверки ≈ 20-25 ₽.
- Бесплатно проверяется ТОЛЬКО введённая страница.
- Платный отчёт (этап 2): главная + до 4 ключевых страниц (политика, оферта, услуги, контакты — автопоиск),
  маршрутизация: 152-ФЗ → формы+политика; реклама → главная+услуги; опечатки → все страницы на Haiku (~1 ₽/стр).
  Себестоимость полного отчёта ≈ 60-120 ₽.
- «Весь сайт до 30 страниц» — отдельный тариф (~2490 ₽), позже по спросу.

## Конкуренты (июль 2026)
- help152.ru — ближайший: freemium, 13 проверок бесплатно, 1490-4900 ₽, штрафы у каждой находки, «426 903 сайта проверено».

- Наше отличие: ИИ читает СМЫСЛ текстов (согласия, обещания, «лучший»), а не только механику;
  готовые исправления; бонусные текстовые проверки.

## Личный кабинет (решено 12.08.2026)
- Вход без пароля: почта → ссылка на 15 минут. Регистрация нужна человеку ради **трёх бесплатных
  проверок в день**, кабинет — приятное следствие, а не причина.
- В кабинете лежат **только купленные отчёты**. Бесплатные не накапливаются.
- Пустой кабинет (зарегистрировался, но не купил) показывает остаток лимита на сегодня и кнопку
  проверки — иначе человек видит пустую полку и не возвращается.
- Разделы: «Мои отчёты», «Оплаты», «Выйти». В «Оплатах» — дата, за что, сумма, ссылка на чек.
  Чек формирует Продамус (Юлия самозанятая, чек через «Мой налог»); отдаёт ли Продамус ссылку
  на чек в вебхуке — НЕ проверено, уточнить при подключении.
- Истёкшая перепроверка не исчезает из списка, а гаснет — чтобы в следующий раз не пропустили окно.

## Технологии и хостинг
- Next.js (App Router), Claude API (sonnet — платный отчёт; для бесплатного можно перевести на haiku).
- Хостинг — ТОЛЬКО в РФ: мы собираем ПД россиян (email) → локализация баз по ч. 5 ст. 18 152-ФЗ.
  Vercel исключён (серверы за рубежом + Hobby запрещает коммерцию + оплата/доступность из РФ).
  Рекомендация: Timeweb Cloud (деплой из GitHub, ~300-400 ₽/мес). Альтернативы: Beget, Amvera.
- БД на этапе 2 — тоже в РФ (managed Postgres у Timeweb), НЕ Supabase (зарубежный, та же локализация).
- Почта hello@sait-checkup.ru — Яндекс 360 для бизнеса (бесплатный тариф на своём домене).
- Этап 2: Продамус (вебхук с подписью), аккаунты magic-link, Telegram-бот уведомлений владельцу.
