# Прогоны моделей

Здесь лежат сырые результаты сравнения моделей на реальных сайтах —
чтобы решения о выборе модели опирались на данные, а не на память.

Папка НЕ уходит в git намеренно: в файлах лежит разбор чужих сайтов
с формулировками вида «нарушение 38-ФЗ». Репозиторий публичный,
и публиковать юридические претензии к чужому бизнесу нельзя.

Выводы и решения по итогам прогонов — в docs/SPEC.md.

Файлы не удалять: перегонять заново стоит денег и времени.
