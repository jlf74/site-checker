# Семейство маскотов линейки приложений

Все продукты линейки используют существ одной породы: круглое тело, один большой глаз,
блик в зрачке, улыбка, румянец. У каждого продукта — свой цвет тела и «профессиональный»
аксессуар. Так приложения узнаются как семья без общего логотипа.

## Фамильная анатомия (не менять)

| Элемент | Параметры (viewBox 0 0 100 100) |
|---|---|
| Тело | круг r=30–34, центр ~(50, 48–52) |
| Глаз | белый эллипс rx=17–19, ry=14–16, чуть выше центра тела |
| Зрачок | круг r=7–8, тёмный `#16233B`, блик r=2.2–2.5 белый со смещением вправо-вверх |
| Улыбка | дуга stroke белый 2.5–3px, `stroke-linecap: round` |
| Румянец | два круга r=3.5–4 по бокам, светлый тон цвета тела, opacity 0.7–0.8 |
| Эмоции | веко (перекрытие глаза), брови-чёрточки, форма улыбки, бейдж-кружок с «!» или «✓» |

## Продукты и цвета

| Продукт | Цвет тела | Румянец | Аксессуар | Где лежит |
|---|---|---|---|---|
| СайтЧекап | `#2563EB` | `#7FA3F2` | лупа (режим «читает») | `components/Mascot.js` (4 состояния + анимации в `app/globals.css`) |

## «Перо» — заготовка для генератора политики

Файл: `policy-generator-pero.svg`. Базовое состояние — «сосредоточенно пишет»:
полуприкрытое веко (цвет века `#5F41C4` — тёмный тон тела), перо в «руке», пунктирная строка.

Состояния для интерфейса генератора (делать по образцу `components/Mascot.js`):
- **idle** — веко убрать, зрачок по центру, перо опущено; моргание как у СайтЧекапа (`m-blink`).
- **writing** — как в SVG; анимации: перо покачивается (класс `m-quill`, вращение ±6° от нижней точки),
  пунктир строки прорисовывается (`stroke-dashoffset`).
- **done** — глаз-дуга «доволен», бейдж-кружок `#1D9E75` с галочкой (как `happy` у СайтЧекапа),
  строка-пунктир заменяется сплошной.

Правила анимации — общие для семейства (см. `app/globals.css`):
- микродвижения 150–300 мс, покачивания 1.6–2.2 с ease-in-out alternate;
- бейджи появляются с пружинкой `cubic-bezier(0.34, 1.56, 0.64, 1)`;
- всё отключается при `prefers-reduced-motion: reduce`.

## Как рождается новый член семьи

1. Взять фамильную анатомию из таблицы выше.
2. Выбрать цвет тела (не повторять существующие), румянец — светлый тон того же цвета.
3. Придумать один аксессуар-профессию (лупа, перо, штамп…) — не больше одного.
4. Сделать 3–4 состояния: idle / «работает» / «нашёл» / «готово».
