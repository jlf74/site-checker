# СайтЧекап

Проверка сайта на юридические риски (152-ФЗ, реклама, образование), орфографию, SEO и убедительность текстов. Работает на Claude API.

Оффер: «Проверьте свой сайт раньше, чем получите штраф». Бесплатно — экспресс-вердикт, полный отчёт — 990 ₽ (Продамус, этап 2).

## Запуск

```bash
npm install
copy .env.example .env.local   # и вписать ANTHROPIC_API_KEY
npm run dev
```

Без ключа приложение работает в демо-режиме (интерфейс тестируется на примерных данных).

## Структура

- `app/page.js` — главная: форма, процесс проверки, бесплатный вердикт с пейволом
- `app/api/proxy/route.js` — загрузка и очистка текста сайта
- `app/api/check/route.js` — одна проверка через Claude (строгий JSON-ответ)
- `lib/checks.js` — каталог проверок, промпты, расчёт оценки
- `app/globals.css` — дизайн-токены (базовый слой для линейки приложений)
- `docs/SPEC.md` — зафиксированные продуктовые решения
- `legacy/` — старая заготовка (CRA + Groq), не используется
